# Somoy (সময়) — Android APK & Messaging Reminder App

যা মনে রাখা দরকার, সময়কে বলুন। বাংলা, বাংলিশ ও ইংরেজিতে মেসেজিং-স্টাইল রিমাইন্ডার এবং অ্যান্ড্রয়েড মোবাইল অ্যাপ।

---

## 📱 গিটহাব থেকে সরাসরি APK বিল্ড ও ফোনে ইনস্টল করার নিয়ম

এই প্রজেক্টটিতে **GitHub Actions** অটোমেশন কনফিগার করা আছে। আপনি গিটহাবে পুশ করলেই স্বয়ংক্রিয়ভাবে একটি অ্যান্ড্রয়েড `.apk` তৈরি হয়ে যাবে!

### ধাপ ১: গিটহাব রিপোজিটরিতে কোড পুশ করুন
আপনার টার্মিনালে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Initial commit - Somoy Android App"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/somoy-app.git
git push -u origin main
```

*(YOUR_USERNAME-এর জায়গায় আপনার গিটহাব ইউজারনেম দিন)*

---

### ধাপ ২: স্বয়ংক্রিয় APK বিল্ড (GitHub Actions)
1. গিটহাবে আপনার রিপোজিটরিতে ঢুকুন।
2. উপরের **"Actions"** ট্যাবে ক্লিক করুন।
3. **"Build Android APK (Somoy)"** নামের ওয়ার্কফ্লোটি স্বয়ংক্রিয়ভাবে চলা শুরু করবে (৩-৪ মিনিট সময় লাগতে পারে)।
4. বিল্ড শেষ হলে নামের পাশে সবুজ টিকচিহ্ন (✓) দেখতে পাবেন।

---

### ধাপ ৩: APK ডাউনলোড ও ফোনে চালানো
1. শেষ হওয়া ওয়ার্কফ্লো রানের উপর ক্লিক করুন।
2. নিচের দিকে **"Artifacts"** সেকশন পাবেন।
3. সেখানে **"Somoy-App-Android-APK"** ফাইলের লিংকে ক্লিক করে জিপ/এপিকে ফাইলটি ডাউনলোড করুন।
4. আপনার অ্যান্ড্রয়েড ফোনে ফাইলটি পাঠান (বা সরাসরি ফোনের ক্রোম ব্রাউজার থেকে গিটহাবে ঢুকে ডাউনলোড করুন)।
5. ডাউনলোড করা `.apk` ফাইলে ট্যাপ করে ইনস্টল করুন। *(যদি ফোনে 'Install unknown apps' অনুমতি চায়, তা Allow করে দিন)*।
6. ব্যস! আপনার ফোনে **সময় (Somoy)** অ্যাপ চালু হয়ে যাবে।

## 💻 লোকাল মেশিনে Android Studio দিয়ে চালানোর নিয়ম (ঐচ্ছিক)

যদি আপনি নিজের কম্পিউটারে Android Studio দিয়ে বিল্ড করতে চান:

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. ওয়েব বিল্ড ও অ্যান্ড্রয়েড প্রজেক্ট সিঙ্ক
npm run build:android

# ৩. অ্যান্ড্রয়েড স্টুডিও ওপেন
npx cap open android
```
অ্যান্ড্রয়েড স্টুডিও ওপেন হলে **Run** বাটনে চাপলেই সরাসরি সংযুক্ত ফোনে বা এমুলেটরে অ্যাপটি চলবে।
